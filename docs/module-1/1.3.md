## Output: three ways, one winner

```csharp
string name = "Ada";
int age = 36;

Console.WriteLine("Name: " + name + ", age: " + age);   // concatenation - clunky
Console.WriteLine("Name: {0}, age: {1}", name, age);    // placeholders - old style
Console.WriteLine($"Name: {name}, age: {age}");         // interpolation - DO THIS
```

The `$` prefix makes an **interpolated string**. Anything inside `{curly braces}` is evaluated
as C# and pasted in. You can put whole expressions inside:

```csharp
Console.WriteLine($"Next year you will be {age + 1}");
Console.WriteLine($"{name.ToUpper()} has {name.Length} letters");
```

## Format specifiers

Add `:format` inside the braces:

| Specifier | Meaning | `1234.5678` becomes |
|---|---|---|
| `F2` | fixed, 2 decimals | `1234.57` |
| `N2` | with thousands separators | `1,234.57` |
| `C` | currency | `£1,234.57` |
| `P1` | percentage | (`0.734` →) `73.4%` |
| `E3` | scientific | `1.235E+003` |
| `D6` | integer, zero-padded | (`42` →) `000042` |
| `X` | hexadecimal | (`42` →) `2A` |

```csharp
Console.WriteLine($"{price:F2}");
Console.WriteLine($"{quantity:D6}");
```

## Alignment

`{value,width}` pads to a width — positive means right-aligned, negative means left-aligned.
This is how you build a table:

```csharp
Console.WriteLine($"|{"Item",-12}|{"Qty",5}|{"Price",10}|");
Console.WriteLine($"|{"Widget",-12}|{3,5}|{9.99,10:F2}|");
```

```
|Item        |  Qty|     Price|
|Widget      |    3|      9.99|
```

Combine both: `{value,10:F2}`.

## Input

```csharp
Console.Write("What is your name? ");
string? typed = Console.ReadLine();
string safeName = typed ?? "stranger";
```

Two things matter:

- `ReadLine()` **always returns a string**, even if the user typed `42`.
- Its type is `string?` — it can be `null` when the input stream ends (for example when input is
  piped from a file). Handle that with `??`.

## Turning text into a number

| Method | On bad input | Use when |
|---|---|---|
| `int.Parse("42")` | **throws** `FormatException` | you are certain it is valid |
| `Convert.ToInt32("42")` | throws; `null` → `0` | converting between types |
| `int.TryParse(s, out int n)` | returns `false` | **user input — almost always this** |

```csharp
if (int.TryParse(typed, out int number))
    Console.WriteLine($"Thanks, {number} is valid.");
else
    Console.WriteLine("That was not a number.");
```

`out int number` declares the variable right there in the call, and `TryParse` fills it in.
(Full explanation of `out` in [1.9](1.9.md).)

## The validation loop you will reuse forever

```csharp
static int ReadIntInRange(string prompt, int min, int max)
{
    while (true)
    {
        Console.Write($"{prompt} ({min}-{max}): ");

        if (int.TryParse(Console.ReadLine(), out int value) && value >= min && value <= max)
            return value;                       // good input - leave the loop

        Console.WriteLine("Sorry, try again.");
    }
}
```

Learn this shape. It is the correct answer to "ask the user for a number" in every program you
will ever write.

## Parsing other types

```csharp
double.TryParse("3.14", out double d);
bool.TryParse("true", out bool flag);
DateTime.TryParse("2026-08-16", out DateTime when);
```

## Reading one key without Enter

```csharp
Console.WriteLine("Press any key...");
ConsoleKeyInfo key = Console.ReadKey(intercept: true);   // true = do not echo
Console.WriteLine($"You pressed {key.Key}");
```

Great for menus and games. The lessons in this course avoid it so the whole syllabus can run
unattended.

## Common mistakes

| Mistake | What happens |
|---|---|
| `int n = Console.ReadLine();` | Compile error — `ReadLine` gives a `string` |
| `int.Parse(Console.ReadLine())` on user input | Crashes on the first typo |
| Forgetting `Console.Write` before `ReadLine` | The user sees no prompt |
| `Console.WriteLine("Total: " + a + b)` | With numbers, `+` concatenates: `"Total: 23"` not `5` |

That last one catches everyone. `"x" + 2 + 3` is `"x23"`. Use `$"Total: {a + b}"`.

## Exercises

1. Ask for two numbers and print their sum, using `TryParse` so it never crashes however rude
   the input.
2. Print a times table from 1 to 12 as a neat aligned grid using `{n,4}`.
3. Ask for a price and a quantity, then print a receipt line with the total formatted as `C`.
4. Write `ReadIntInRange` yourself and use it to build a menu that only accepts 1–4.
