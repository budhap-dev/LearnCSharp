## The GCSE distinction

- **Count-controlled** — you know how many repeats → `for`
- **Condition-controlled** — you repeat until something becomes true → `while` / `do-while`

## `for`

```
FOR i ← 1 TO 5           for (int i = 1; i <= 5; i++)
    OUTPUT i             {
ENDFOR                       Console.WriteLine(i);
                         }
```

Three parts, separated by semicolons:

```csharp
for (initialise; keep going while; do after each pass)
```

All three are optional — `for (;;)` is an infinite loop.

```csharp
for (int i = 10; i >= 0; i -= 2)     // count down in twos
for (int i = 1; i <= 100; i *= 2)    // 1, 2, 4, 8, 16...
for (int i = 0, j = 10; i < j; i++, j--)   // two counters
```

> Programmers usually count **from 0**, because arrays are indexed from 0.
> `for (int i = 0; i < n; i++)` runs exactly *n* times. Learn that shape by heart.

### Off-by-one errors

| Loop | Iterations |
|---|---|
| `for (i = 0; i < 5; i++)` | 5 |
| `for (i = 0; i <= 5; i++)` | **6** |
| `for (i = 1; i <= 5; i++)` | 5 |

Getting this wrong is called an **off-by-one error** and it is the most frequent loop bug there
is. With arrays, `i <= array.Length` throws `IndexOutOfRangeException`.

## `while`

Checked **before** the first pass, so the body may run **zero** times.

```csharp
int total = 0, n = 1;
while (total < 50)
{
    total += n;
    n++;
}
```

Use it when you do not know the number of repeats in advance.

## `do`-`while`

Checked **after** the body, so it always runs **at least once**. Note the semicolon at the end.

```csharp
do
{
    Console.Write("Enter 1-10: ");
    input = ReadNumber();
}
while (input < 1 || input > 10);
```

Perfect for menus and input validation: you must always ask once before you can check the answer.

## `foreach`

```csharp
foreach (string planet in planets)
{
    Console.WriteLine(planet);
}
```

The **safest** loop: no counter to get wrong, and you cannot go out of bounds.

Two restrictions:

- You **cannot add to or remove from** the collection during a `foreach` — that throws
  `InvalidOperationException`.
- Assigning to the loop variable does not change the collection.

Need to modify items? Use a `for` loop. Need to remove them? Use `RemoveAll`, or loop backwards.

## `break` and `continue`

```csharp
for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0) continue;   // skip to the next iteration
    if (i > 7) break;           // leave the loop entirely
    Console.Write(i);
}
```

The classic `break` is a linear search — stop as soon as you find it:

```csharp
for (int i = 0; i < data.Length; i++)
{
    if (data[i] == target) { foundAt = i; break; }
}
```

## Nested loops

A loop inside a loop. The inner loop runs **completely for each pass** of the outer one, so the
total work is *outer × inner*.

```csharp
for (int row = 1; row <= 4; row++)
{
    for (int col = 1; col <= 4; col++)
        Console.Write($"{row * col,4}");

    Console.WriteLine();
}
```

Two nested loops over *n* items is **O(n²)** — see [5.1](../module-5/5.1.md).

> `break` only leaves the **innermost** loop. To leave both, use a flag, or extract the loops
> into a method and `return`.

## Infinite loops

```csharp
while (true)              // deliberate: a game loop or menu loop
{
    DoOneTurn();
    if (playerQuit) break;      // you MUST have an exit
}

int i = 0;
while (i < 10)            // accidental: nothing ever changes i
{
    Console.WriteLine(i);       // forgot i++  -> runs forever
}
```

If your program hangs, press **Ctrl+C**, then ask: does something in the loop actually move the
condition towards false?

## Choosing

| Situation | Loop |
|---|---|
| Known repeats, need the index | `for` |
| Every item in a collection | `foreach` |
| Repeat until true, may be zero times | `while` |
| Repeat until true, at least once | `do-while` |
