## The idea

An array's size is fixed the moment you create it ([1.7](../module-1/1.7.md)). `List<T>` wraps
an array and manages the resizing for you — it is the collection you reach for **by default**.

```csharp
List<string> shopping = new();
shopping.Add("bread");
shopping.Add("milk");
shopping.AddRange(["eggs", "butter"]);

List<int> primes = [2, 3, 5, 7, 11];      // collection expression
```

The `<string>` is a *type argument* — generics, covered properly in [3.4](3.4.md). The compiler
guarantees this list can only ever hold strings.

## Reading, inserting, removing

```csharp
shopping[0]              // indexed like an array
shopping[^1]             // last item
shopping.Count           // note: Count, not Length

shopping.Insert(1, "jam");            // shuffles everything after it right
shopping.Remove("milk");              // by VALUE - removes the first match only
shopping.RemoveAt(0);                 // by index
shopping.RemoveAll(s => s.StartsWith('b'));   // every match, by predicate
```

`Remove` returns `false` rather than throwing when the value is absent. `RemoveAt` with a bad
index throws `ArgumentOutOfRangeException`.

## Searching

| Method | Returns | For |
|---|---|---|
| `Contains(42)` | `bool` | is it there? |
| `IndexOf(42)` | index or **−1** | where is it? |
| `Find(v => v > 50)` | first match or `default` | first matching item |
| `FindIndex(v => v > 50)` | index or −1 | where is the first match? |
| `FindAll(v => v > 20)` | a new `List<T>` | every match |
| `Exists(v => v < 0)` | `bool` | does any match? |
| `TrueForAll(v => v > 0)` | `bool` | do all match? |

The `v => ...` arguments are lambdas — [4.2](../module-4/4.2.md) covers them fully; for now,
read them as "a rule to test each item against".

## Sorting

```csharp
list.Sort();                              // ascending, in place
list.Sort((a, b) => b.CompareTo(a));      // custom order: descending
list.Reverse();                           // reverses in place

jobs.Sort((a, b) => b.Priority.CompareTo(a.Priority));   // objects, by one property
```

`Sort` changes the list **in place** and returns nothing. LINQ's `OrderBy` ([3.6](3.6.md))
returns a new sequence and leaves the original alone — a common point of confusion.

## The rule you must not break

**Do not add or remove while `foreach`-ing the same list.** It throws
`InvalidOperationException` — the enumerator detects the change and refuses to continue with a
possibly-corrupt position.

```csharp
foreach (int n in numbers)
    if (n % 2 == 0) numbers.Remove(n);    // InvalidOperationException
```

Safe alternatives, best first:

```csharp
numbers.RemoveAll(n => n % 2 == 0);       // 1. built for the job

for (int i = numbers.Count - 1; i >= 0; i--)   // 2. loop BACKWARDS by index
    if (numbers[i] % 2 == 0) numbers.RemoveAt(i);
```

Backwards, because removing item 3 shifts everything after it left — iterating forwards you
would skip the item that just slid into position 3.

## How the growth actually works

A `List<T>` holds a private array. `Add` places the item in the next free slot — until the
array is full, at which point the list allocates an array **twice the size** and copies
everything across.

```
Count:     1   2   3   4   5   ...  9   ...  17
Capacity:  4   4   4   4   8   ...  16  ...  32
```

Run the lesson to watch the capacity double in real time.

Two consequences:

- `Add` is **O(1) amortised** — occasionally one add pays for a full copy, but averaged over
  many adds it is constant.
- If you know the final size, say so and skip every copy:

```csharp
List<int> scores = new(10_000);       // capacity hint - no resizing ever happens
```

## Array vs List

| | Array | `List<T>` |
|---|---|---|
| Size | fixed | grows and shrinks |
| Access by index | O(1) | O(1) |
| Add at end | ✗ | O(1) amortised |
| Insert / remove at position | ✗ / manual shuffle | O(n) — it shuffles for you |
| Methods | few | dozens |
| Use when | size is truly fixed | **everything else** |

## Common mistakes

| Mistake | Fix |
|---|---|
| `list.Length` | It is `Count` on collections, `Length` on arrays |
| Removing inside `foreach` | `RemoveAll`, or a backwards `for` |
| Expecting `Sort()` to return the sorted list | It sorts in place and returns `void` |
| `Remove(x)` assuming all copies go | It removes the **first** match only |
| Growing a huge list from default capacity | Pass the expected size to the constructor |
