## The idea

Finding an item in a `List` means checking items one by one — O(n). A `Dictionary<TKey, TValue>`
computes **where the item lives from the key itself** and jumps straight there — O(1).

This is the single biggest performance upgrade available to a beginner, and it also makes code
*clearer*: "the age **of** Ada" instead of "loop until you find Ada, then take her age".

```csharp
Dictionary<string, int> ages = new()
{
    ["Ada"] = 36,
    ["Alan"] = 41,
    ["Grace"] = 85,
};

ages["Ada"]          // 36
ages["Edsger"] = 72; // adds if missing
ages["Ada"] = 37;    // overwrites if present
```

## Writing: indexer vs Add

| | Key already exists | Key missing |
|---|---|---|
| `ages["Ada"] = 37` | overwrites | adds |
| `ages.Add("Ada", 37)` | **throws** `ArgumentException` | adds |
| `ages.TryAdd("Ada", 37)` | returns `false` | adds, returns `true` |

Use `Add` when a duplicate would be a bug you want to hear about; the indexer when overwriting
is fine.

## Reading safely

```csharp
ages["Nobody"]                          // KeyNotFoundException!

if (ages.TryGetValue("Grace", out int age)) { ... }   // the professional habit

ages.GetValueOrDefault("Nobody")        // 0    (the type's default)
ages.GetValueOrDefault("Nobody", -1)    // -1   (your fallback)
ages.ContainsKey("Nobody")              // false
```

`TryGetValue` is the same pattern as `TryParse` ([1.3](../module-1/1.3.md)): a `bool` for
success and an `out` parameter for the value.

## The classic use: counting things

```csharp
Dictionary<string, int> counts = new();

foreach (string word in text.Split(' '))
    counts[word] = counts.GetValueOrDefault(word) + 1;
```

Missing word → `GetValueOrDefault` gives 0 → we store 1. Present → increment. Two lines that
appear in some form in half of all real programs: word frequency, vote tallies, histogram
buckets, inventory counts.

## Looping over a dictionary

```csharp
foreach (KeyValuePair<string, int> pair in ages)
    Console.WriteLine($"{pair.Key} is {pair.Value}");

ages.Keys      // just the keys
ages.Values    // just the values
```

> ⚠️ The order you get items back is **not guaranteed**. If you need order, sort the keys, or
> use a `SortedDictionary` (kept sorted, O(log n) instead of O(1)).

## Keys can be almost anything

```csharp
Dictionary<int, string> byId = new();

// A record works because records compare by VALUE (2.9):
Dictionary<Point, string> grid = new() { [new Point(0, 0)] = "origin" };

// Case-insensitive string keys:
Dictionary<string, int> lookup = new(StringComparer.OrdinalIgnoreCase);
```

A good key type must have correct `Equals` and `GetHashCode` ([2.10](../module-2/2.10.md)) and
must be **immutable** — mutate a key after insertion and the entry is lost in the wrong bucket
([5.9](../module-5/5.9.md) shows this happening).

## HashSet: a bag of unique values

A `HashSet<T>` is a dictionary with no values — just fast membership.

```csharp
HashSet<string> visited = ["London", "Paris", "London", "Tokyo"];
visited.Count                  // 3 - the duplicate collapsed
visited.Add("Paris")           // false - already there
visited.Contains("Tokyo")      // true - O(1)
```

`Add` returning `bool` is quietly useful: "process each item once" becomes
`if (seen.Add(item)) { ... }` — test and record in one call. The graph searches in
[5.8](../module-5/5.8.md) depend on exactly this.

## Set operations

```csharp
HashSet<int> a = [1, 2, 3, 4, 5];
HashSet<int> b = [4, 5, 6, 7];

a.UnionWith(b);       // a becomes 1,2,3,4,5,6,7
a.IntersectWith(b);   // what is in both
a.ExceptWith(b);      // what is only in a
a.IsSubsetOf(b);      // bool
```

These mutate the set in place. The LINQ versions — `Union`, `Intersect`, `Except`
([3.6](3.6.md)) — return a new sequence instead.

## The speed difference is not subtle

From the lesson, 2,000 lookups in 200,000 items:

```
List.Contains      ~1500 ms      checks every item
HashSet.Contains      ~0 ms      jumps straight to the bucket
```

How hashing achieves this is [5.9](../module-5/5.9.md) — for now, trust the API.

## Choosing

| Need | Use |
|---|---|
| Look up a value by a key | `Dictionary<K,V>` |
| "Have I seen this before?" | `HashSet<T>` |
| Keys in sorted order | `SortedDictionary<K,V>` |
| Just a growable sequence | `List<T>` |

## Common mistakes

| Mistake | Result |
|---|---|
| `dict["missing"]` | `KeyNotFoundException` — use `TryGetValue` |
| Relying on insertion order | Not guaranteed |
| Mutable object as a key | Entry becomes unfindable |
| `List.Contains` in a loop over big data | Accidentally O(n²) — use a set |
| `Add` when overwrite was intended | `ArgumentException` |
