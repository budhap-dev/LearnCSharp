## The one fact that matters: strings are immutable

Every string method that *looks* like it changes a string actually returns a **new** string and
leaves the original alone.

```csharp
string original = "hello";
original.ToUpper();               // does NOTHING - result thrown away
string shouted = original.ToUpper();   // correct
```

Why? Immutability makes strings safe to share between threads, safe as dictionary keys, and
allows the runtime to reuse identical literals. The cost shows up in loops — see StringBuilder
below.

## Indexing and slicing

```csharp
string word = "Computer";

word.Length      // 8
word[0]          // 'C'    (a char)
word[^1]         // 'r'
word[0..4]       // "Comp"
word.Substring(0, 4)   // "Comp"  - same thing
```

A string behaves like a **read-only** char array. `word[2] = 'x'` will not compile.

## Searching

| Method | Returns |
|---|---|
| `Contains("brown")` | `bool` |
| `StartsWith` / `EndsWith` | `bool` |
| `IndexOf("fox")` | index, or **−1** if absent |
| `LastIndexOf("the")` | index of the last occurrence |

> `IndexOf` returns **−1**, not null, when it finds nothing. Always check for −1 before using
> the result as an index.

## Transforming (each returns a new string)

```csharp
s.ToUpper()  s.ToLower()
s.Replace("lazy", "sleepy")
s.Substring(4, 5)          // start at 4, take 5
s.Insert(0, ">> ")
s.Remove(3)                // keep the first 3
s.Trim()  s.TrimStart()  s.TrimEnd()
s.PadLeft(8, '.')  s.PadRight(8)
```

## Split and Join

```csharp
string[] parts = "Ada,Alan,Grace".Split(',');
string joined  = string.Join(" and ", parts);

// Cleaning messy input in one step:
"one,,two,  three ,".Split(',',
    StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries)
// -> ["one", "two", "three"]
```

`Split(' ')` on a sentence gives you the words — the basis of half of all text exercises.

## Comparing

```csharp
"abc" == "abc"    // true  - C# compares the CHARACTERS
"ABC" == "abc"    // false - case sensitive
"ABC".Equals("abc", StringComparison.OrdinalIgnoreCase)   // true
string.Compare(a, b, StringComparison.Ordinal)            // <0, 0, >0 for sorting
```

> In C# `==` on strings compares contents, which is what you want. In Java it compares
> references and catches everyone out. C# is friendlier here.

## Empty, null, whitespace

```csharp
string.IsNullOrEmpty("")          // true
string.IsNullOrEmpty("   ")       // FALSE - spaces are characters
string.IsNullOrWhiteSpace("   ")  // true
```

Use `IsNullOrWhiteSpace` when validating user input — someone pressing space then Enter should
not count as typing a name.

## Escape sequences and literal strings

```csharp
"Line one\nLine two"      // \n new line
"Tab\there"               // \t tab
"She said \"hi\""         // \" a literal quote
"C:\\Users\\Ada"          // \\ a literal backslash

@"C:\Users\Ada"           // verbatim: backslashes are literal

string json = """
    { "name": "Ada", "age": 36 }
    """;                  // raw string literal (C# 11) - quotes need no escaping
```

## StringBuilder — the performance lesson

Because strings are immutable, `text += x` inside a loop creates a **brand new string every
pass** and throws the old one away. Building 20,000 characters that way copies about 200 million
characters.

```csharp
// Slow: ~200 ms for 20,000 iterations
string slow = "";
for (int i = 0; i < 20000; i++) slow += "x";

// Fast: ~1 ms - one growable buffer
StringBuilder builder = new();
for (int i = 0; i < 20000; i++) builder.Append('x');
string fast = builder.ToString();
```

Run the lesson to see the real numbers on your machine.

| Building… | Use |
|---|---|
| A handful of strings | `$"..."` or `string.Join` |
| Text inside a loop | `StringBuilder` |

`StringBuilder` methods: `Append`, `AppendLine`, `AppendFormat`, `Insert`, `Remove`, `Replace`,
`Clear`, and `ToString()` once at the end.

## `char` helpers

```csharp
char.IsDigit('7')  char.IsLetter('a')  char.IsUpper('A')
char.IsWhiteSpace(' ')  char.IsLetterOrDigit('!')
char.ToUpper('a')  char.ToLower('A')
(int)'A'           // 65 - its Unicode code point
```

## Common mistakes

| Mistake | Fix |
|---|---|
| `s.ToUpper();` alone on a line | Assign the result |
| `s[0] = 'x'` | Strings are read-only — rebuild the string |
| Using `IndexOf` result without checking for −1 | Check first |
| `+=` in a big loop | `StringBuilder` |
| `s.Substring(start, end)` | The second argument is a **length**, not an end index |
| `IsNullOrEmpty` on `"   "` | Use `IsNullOrWhiteSpace` |
