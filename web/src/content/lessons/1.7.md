## The idea

An array is a **fixed-size** block of same-typed values laid out side by side in memory. Because
they are contiguous, the computer can jump straight to any item: `array[500]` is just
"start address + 500 × item size". That is why array access is **O(1)**.

## Creating

```csharp
int[] scores = new int[5];              // 5 slots, all 0
int[] primes = { 2, 3, 5, 7, 11 };      // sized from the list
int[] more   = new int[] { 2, 3, 5 };   // the long way
int[] modern = [2, 3, 5];               // C# 12 collection expression
string[] names = ["Ada", "Alan", "Grace"];
```

New arrays are filled with the type's default: `0`, `false` or `null`.

> An array's size is **fixed** the moment it is created. You cannot append to it. When you need
> to grow, use `List<T>` — [3.1](../module-3/3.1.md).

## Indexing starts at zero

```csharp
primes[0]                   // first
primes[primes.Length - 1]   // last
primes[^1]                  // last, index-from-end operator
primes[^2]                  // second from last
```

Valid indexes are `0` to `Length - 1`. Anything else throws `IndexOutOfRangeException`
immediately.

> In C or C++ that same line would silently read random memory. C#'s bounds check costs a few
> nanoseconds and buys you memory safety — the core trade-off behind managed languages.

## Ranges

```csharp
primes[1..4]    // index 1 up to, NOT including, 4
primes[..3]     // start to 3
primes[2..]     // 2 to the end
primes[^2..]    // the last two
```

## The classic algorithms

Write each of these by hand at least once — they are exam staples.

```csharp
// Sum and average
int sum = 0;
foreach (int v in data) sum += v;
double average = (double)sum / data.Length;      // note the cast!

// Max, min and the index of the max
int max = data[0], min = data[0], maxIndex = 0;
for (int i = 1; i < data.Length; i++)
{
    if (data[i] > max) { max = data[i]; maxIndex = i; }
    if (data[i] < min) min = data[i];
}

// Count matching
int above20 = 0;
foreach (int v in data) if (v > 20) above20++;
```

> ⚠️ Start `max` at `data[0]`, **not** at `0`. If every value were negative, starting at 0 would
> give the wrong answer. This is a favourite exam trap.

## Arrays are reference types

```csharp
int[] alias = data;     // copies the ARROW, not the boxes
alias[0] = 999;         // data[0] is now 999 too!
```

Both names point at the same array. For a genuine copy:

```csharp
int[] copy = data.ToArray();
int[] copy2 = (int[])data.Clone();
Array.Copy(data, copy3, data.Length);
```

## Useful `Array` methods

| Method | Does |
|---|---|
| `Array.Sort(a)` | sorts in place |
| `Array.Reverse(a)` | reverses in place |
| `Array.IndexOf(a, v)` | first index, or −1 |
| `Array.BinarySearch(a, v)` | fast search — **sorted arrays only** |
| `Array.Fill(a, v)` | sets every slot |
| `Array.Exists(a, p)` | any match? |
| `Array.Resize(ref a, n)` | makes a **new** array and copies |

## 2D arrays — grids

Perfect for game boards, seating plans and tables. One rectangular block of memory.

```csharp
int[,] grid = new int[3, 4];     // 3 rows, 4 columns
grid[1, 2] = 9;                  // row 1, column 2

char[,] board =
{
    { 'X', 'O', 'X' },
    { 'O', 'X', 'O' },
    { 'X', 'O', 'X' },
};

for (int row = 0; row < grid.GetLength(0); row++)
    for (int col = 0; col < grid.GetLength(1); col++)
        ...
```

| Member | Gives |
|---|---|
| `GetLength(0)` | number of rows |
| `GetLength(1)` | number of columns |
| `Length` | rows × columns |

> 2D arrays use `GetLength(dimension)`, **not** `Length`, for the row or column count.

## Jagged arrays — arrays of arrays

Each row can be a different length. Written `int[][]`, indexed `[row][col]`.

```csharp
int[][] triangle =
[
    [1],
    [1, 1],
    [1, 2, 1],
    [1, 3, 3, 1],
];

triangle.Length       // 4  (rows)
triangle[3].Length    // 4  (that row's length)
triangle[3][1]        // 3
```

| | `int[,]` rectangular | `int[][]` jagged |
|---|---|---|
| Memory | one block | array of references |
| Row lengths | all equal | can differ |
| Speed | slightly faster | one extra hop |
| `foreach` over a row | no | yes |

## Common mistakes

| Mistake | Fix |
|---|---|
| `for (i = 0; i <= a.Length; i++)` | Use `<`, not `<=` |
| `a[a.Length]` | The last index is `Length - 1` |
| `int max = 0;` with negative data | Start at `data[0]` |
| `b = a;` expecting a copy | Use `a.ToArray()` |
| `grid.Length` for the row count | Use `grid.GetLength(0)` |
| Trying to append to an array | Use `List<T>` |

1. Write a method returning the **second-largest** value in an `int[]` without sorting it.
2. Build a 3×3 noughts-and-crosses board and write a method that detects a winning line.
3. Store 5 students × 4 subjects of marks in a 2D array; print each student's average and each
   subject's average.
